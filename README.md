# Abdullah Khalid - Portfolio Website 🚀

Welcome to the personal portfolio website of **Abdullah Khalid**. This interactive portfolio showcases my projects, skills, 3D interactive experiences, and professional background.

---

## 🛠️ Tech Stack & Features

- **Frontend:** React 18, TypeScript, Vite
- **3D & Visuals:** Three.js, `@react-three/fiber`, `@react-three/drei`, WebGL
- **Animations:** GSAP (GreenSock), ScrollTrigger, SplitText
- **Styling:** Custom CSS, Responsive & Interactive Design

---

## 🚀 Getting Started Locally

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abdulah-0/Portfolio-Abdullah-Khalid.git
   cd Portfolio-Abdullah-Khalid
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
